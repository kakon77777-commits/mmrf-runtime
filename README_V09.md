# MMRF v0.9 Scientific Federation & Dataset Governance

This release adds:

- signed cross-node shard catalogs;
- replication-factor measurement and repair;
- schema migration from 0.8 to 0.9;
- source-CID to target-CID lineage;
- signed dataset proposals;
- independent 2-of-3 review;
- safety-gated promotion receipts;
- provenance DAGs;
- persistent dataset citations;
- a 26-check release-candidate conformance suite.

Only L0 public mathematical data can be promoted. Source-factor relations,
RSA-target queries, factor candidates, range narrowing, exact-list endpoints
and raw-factor export remain disabled.
