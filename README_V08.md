# MMRF v0.8 Data Lake & Scientific Query Plane

This release adds a two-generation public mathematical data lake:

- immutable 100,000-integer columnar shards;
- logical content-addressed CIDs;
- compressed NPZ storage;
- manifest hash chaining;
- incremental append without rewriting prior shards;
- aggregate-only MMRF-SQL 0.8;
- column pruning;
- replayable scientific workflows;
- mirror integrity sampling and corruption detection.

No source–factor relationship, RSA target, factor candidate or exact-prime-list
endpoint is included.
