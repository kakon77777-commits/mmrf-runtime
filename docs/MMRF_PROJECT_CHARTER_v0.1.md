## 2. 核心定位

MMRF 不是單純保存質數序列的資料庫，而是保存下列研究對象的長期資料網格：

1. 質數本體與素性證書；
2. 質數間距、密度與局部結構；
3. 模剩餘簽章與多尺度分類；
4. 質數族、質數鏈與算術級數；
5. MMPF 路由、排除、分裂與重建觀測；
6. 不同演算法、機器與資料表示的性能；
7. 可重播研究實驗與失敗紀錄；
8. 數學、計算、物理與防禦性密碼學所需的派生資料。

MMRF 的長期目標是：

> 將大量、異質、跨尺度的質數研究資料轉化為可驗證、可索引、可重播、可授權調閱的研究基礎設施。

---

## 3. 與 MMPF／3M 的關係

```text
原始整數、候選與研究問題
        ↓
MMPF：分解、候選排除、路由與證書
        ↓
MLF：保存資料、座標、關係、來源與轉換損失
        ↓
MMLC：執行、約束檢查、不變量與審計
        ↓
MMR：比較表示、路由、機器與可重播性
        ↓
MMRF：長期累積、索引、分級授權與研究調閱
```

因此：

\[
\boxed{\text{MMPF 是計算 Runtime，MMRF 是長期研究資料網格。}}
\]

## 4. 公益研究目的

MMRF 可以服務：

- 質數分布與間距研究；
- 算法設計與複雜度實驗；
- 高性能計算；
- 數值方法；
- 數學物理；
- 隨機模型與統計力學類比；
- 可驗證計算；
- 防禦性密碼學；
- 弱金鑰生成機制研究；
- 後量子遷移與密碼安全評估。

## 5. 密碼學非武器化原則

MMRF 不提供以下能力：

1. 接受任意第三方 RSA 模數並回傳候選質因數；
2. 針對指定公開金鑰縮小因數搜尋區間；
3. 以 API 形式提供 target-conditioned factor lookup；
4. 對未知權利人的真實金鑰進行批次分析；
5. 匯出能直接重建高敏感關聯索引的完整資料；
6. 將內部縮減模型包裝成外部「RSA 破解服務」。

一個普通質數列表本身通常不足以威脅現代 RSA。真正敏感的是：

- 與目標模數條件化後的候選排序；
- 能大幅縮減搜尋空間的關聯索引；
- 特定位數層的結構化因數鄰域；
- 可重播的高成功率分解路由；
- 大規模目標查詢與交叉比對能力。

因此 MMRF 的安全重點不是「隱藏所有質數」，而是限制：

\[
\boxed{\text{目標條件化查詢}+\text{敏感關聯索引}+\text{大規模可逆匯出}}
\]

## 6. 研究允許範圍

允許的密碼學研究包括：

- 教學尺寸或人工脆弱 RSA 測試向量；
- 研究者自己擁有並明確授權的測試金鑰；
- 已公開、已失效或專為研究發布的挑戰數；
- 弱亂數、重複質數、共享因數與錯誤金鑰生成研究；
- RSA 安全參數、金鑰生成與防禦檢測研究；
- 後量子遷移與風險評估；
- 不輸出第三方私鑰的統計性研究。

## 7. 四級資料分類

### L0 — Public

可以公開下載或公開 API 查詢：

- 一般質數紀錄；
- 小型與中型研究資料；
- 聚合統計；
- 質數間距分布；
- 非目標條件化的模剩餘統計；
- 素性證書與驗證工具；
- 公開論文重現資料。

### L1 — Registered Research

需要研究帳號與用途聲明：

- 大型聚合資料；
- 較細的多尺度統計；
- 受速率限制的研究查詢；
- 高成本但不具直接破解性的派生資料；
- 經過降解析度或去目標化的結構資料。

### L2 — Controlled Research Enclave

需要正式申請與雙重審批：

- 高敏感結構索引；
- 與密碼安全相關的高位數研究；
- 大型因數分解路由與失敗／成功資料；
- 可能縮減候選空間但尚未直接輸出因數的模型；
- 只能在受控環境運算，原始資料不可直接匯出。

### L3 — Founder-Controlled Vault

完整資料只存在於受控 Vault：

- 未降解析度的全量關係資料；
- 目標條件化後可能具有密碼分析價值的索引；
- 未公開的 MMRF 核心模型；
- 敏感研究快照；
- 安全事故、濫用模式與內部紅隊結果。

L3 的調閱原則是：

\[
\boxed{\text{資料所有者授權}+\text{安全管理者授權}+\text{用途限定}+\text{完整審計}}
\]

不得只依賴單一密碼或單一管理者意志。

## 8. 查詢安全模型

每個查詢都必須經過：

```text
身份驗證
→ 用途判定
→ 資料級別判定
→ 查詢形狀檢查
→ 風險評分
→ 預算與速率限制
→ 執行
→ 結果降解析／遮罩
→ 追加式審計
```

高風險查詢形狀包括：

- 提交外部大型合數並要求候選質數；
- 對同一模數反覆改變條件查詢；
- 大量掃描特定位數、特定模餘數與特定鄰域；
- 交叉連接多個敏感索引以重建候選集合；
- 匯出大量細粒度關係資料；
- 試圖以多個帳號繞過查詢預算。

## 9. 資料最小單位

### PrimeRecord

保存單一質數的：

- 數值或安全識別；
- bit length；
- 十進位位數；
- 模剩餘簽章；
- 前後質數間距；
- 質數族標記；
- 素性證書；
- 來源與生成方法；
- 驗證狀態；
- 安全分類。

### RelationRecord

保存：

- twin prime；
- cousin prime；
- sexy prime；
- Sophie Germain prime；
- safe prime；
- prime k-tuple；
- 算術級數；
- 其他研究關係。

### ResearchRun

保存：

- 問題定義；
- 軟體與演算法版本；
- 機器校準；
- 輸入範圍；
- 查詢與路由；
- 成功與失敗；
- 執行證書；
- MLF／MMLC／MMR 指紋。

### AggregateIndex

只保存：

- 計數；
- 直方圖；
- 分位數；
- 密度；
- 非可逆摘要；
- 可公開的區間統計。

## 10. 完整調閱原則

「完整調閱」不是一般 API 權限，而是一次受控研究事件。

每次完整調閱必須記錄：

- 申請者；
- 研究目的；
- 對應資料集；
- 允許的運算；
- 禁止的運算；
- 允許的輸出形式；
- 開始與終止時間；
- 審批者；
- 工作環境；
- 執行雜湊；
- 匯出物；
- 結案審查。

高敏感研究預設：

```text
資料進入受控運算環境
研究者進入環境分析
只有核准的聚合結果可以離開
```

而不是把完整資料下載給研究者。

## 11. 第一階段里程碑

### MMRF v0.1 — Foundation

- 計畫憲章；
- 安全政策；
- 分級模型；
- PrimeRecord／ResearchRun schema；
- 公開安全範例；
- 3M 整合位置。

### MMRF v0.2 — Ingestion

- 匯入 MMPF 證書；
- 素性證書驗證；
- MLF 正規化；
- MMLC 驗證事件；
- MMR benchmark metadata；
- 去重與內容指紋。

### MMRF v0.3 — Public Research Index

- 公開聚合查詢；
- 質數間距與密度；
- 質數族索引；
- 可重播研究資料集；
- 禁止 target-conditioned 查詢。

### MMRF v0.4 — Controlled Enclave

- L2 安全研究空間；
- 查詢風險評分；
- 研究者審批；
- 結果輸出審查；
- 追加式安全審計。

### MMRF v1.0 — Authorized Research Fabric

- 長期資料生命週期；
- 多機器與多來源同步；
- 完整治理；
- 公開／限制／Vault 三層部署；
- 可驗證的研究調閱與發布流程。

---

## 12. 現階段明確不做

v0.1 不建立：

- RSA modulus factor API；
- 真實第三方金鑰測試服務；
- 高位數候選縮減端點；
- 可下載的敏感全量關係表；
- 自動核准密碼分析查詢；
- 任何聲稱可以破解現代 RSA 的公開功能。

---

## 13. 計畫總命題

\[
\boxed{\text{最大化質數研究的可用性}\quad\text{同時}\quad\text{最小化資料被轉化為未授權密碼分析能力的可能性}}
\]

MMRF 的價值不是「知道所有質數」，而是建立：

> 可驗證、可組合、可長期累積，又能被治理的質數研究記憶體。
