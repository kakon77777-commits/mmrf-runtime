# MMRF v0.1–v1.0 Historical Integration Map

| Version | Stable contribution |
|---|---|
| v0.1 | Project charter, four-level classification and non-weaponization policy |
| v0.2 | Early typed record and controlled-query design work, absorbed into later schemas |
| v0.3 | Pre-Enclave authorization and audit design, superseded by v0.4 controls |
| v0.4 | Controlled Research Enclave, dual approval and egress scanning |
| v0.5 | Federated encrypted Vault, content addressing and checkpoint replication |
| v0.6 | Transparency log, witness quorum, key rotation, revocation and recovery |
| v0.7 | Independent policy authority, mandatory mTLS and real multi-process trial |
| v0.8 | Incremental public mathematical data lake and aggregate scientific queries |
| v0.9 | Signed federation catalogs, schema governance, provenance and citation |
| v1.0 | Stable contracts, installation profiles, threat model, operations and release freeze |

The v1.0 package preserves historical source and evidence where available.
v0.2 and v0.3 are represented as superseded design stages because no separate
standalone release directory exists in the current integrated workspace.
